# 本地网页

```bash
python -m pip install -e '.[web]'
mendpilot-web --port 8765 --output-dir artifacts/web
```

服务固定监听 `127.0.0.1`，使用当前 Python 解释器启动独立修复进程；需要 Linux/macOS、bash 和 git。远端运行时可通过 SSH 转发端口，再在本机访问。

操作顺序：拖入或选择单个 UTF-8 `.py` 文件（最大 1 MiB），填写修复说明、服务模型名称、API 地址、API 格式及凭据，点击启动。两种 API 格式均可使用。每次仅运行一个任务；运行中可查看日志、停止任务，完成后查看补丁、下载修复文件或补丁。

网页只处理单文件本地修复，不提供项目上传、Docker、自定义测试命令或基准评测。文件依赖项目内其他模块时，改用 CLI 的 `--project`。上传文件保留为输入，修复在副本进行；停止会终止执行中的命令。网页的本地执行权限与启动服务的用户相同。

任务放在 `--output-dir/<task-id>/`，包含输入、运行日志和 CLI 同类修复产物。密钥通过标准输入传给工作进程，不存入配置、命令行或结果；服务的任务列表只保留当前进程内状态。重启后旧结果可在磁盘查看。服务使用本机 Host/Origin 校验与会话令牌，不提供公开部署模式。
